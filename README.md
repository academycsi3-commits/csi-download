# CSI Download

**Le gestionnaire de téléchargement de CSI Academy** — Ouagadougou, Burkina Faso.

- Téléchargements accélérés (plusieurs connexions qui s'entraident) et reprise après coupure
- Vidéos, files d'attente avec horaires, plafond de données et forfait mensuel
- Antivirus après chaque téléchargement, mots de passe chiffrés, mises à jour signées

## Télécharger

Les versions officielles sont dans **[Releases](../../releases)** : prenez le fichier
`CSIDownload-Installation-X.Y.exe` de la dernière version.

Chaque version est accompagnée d'une signature (`.exe.sig`) : CSI Download vérifie lui-même, avant
toute mise à jour automatique, qu'elle vient bien de CSI Academy.
